# QTest 详细报告模板索引

模板 v3，共 9 类。用于定义报告应包含的内容；未实现的测试插件在模板中明确标记。

- [单机总报告](01-system-overview.md)：全部参测系统；汇总 L0、L1、L2，不能用内核成绩替代应用成绩。
- [哈密顿量模拟专项报告](02-hamiltonian.md)：原生或数字演化；比较前冻结同一模型、初态和观测语义。
- [玻色采样专项报告](03-boson-sampling.md)：显式区分 Fock 与 GBS；当前自动执行器仅支持小规模 Fock 样例。
- [约束优化场景报告](04-optimization.md)：资源选择／冲突图 MIS；评价原图的可行解与目标值。
- [分子能量与 VQE 场景报告](05-vqe.md)：正式化学数据需完整电子结构定义；当前两比特模型仅作联调。
- [材料动力学场景报告](06-material-dynamics.md)：首期核心场景；已含小规模 1D Ising 链联调插件（连通关联与结构因子轨迹），完整材料套件仍未实现。
- [分类场景报告](07-classification.md)：首期核心场景的设计模板；当前自动测试插件尚未实现。
- [光子应用场景报告](08-photonic-applications.md)：GBS 稠密子图或振电光谱；先核实设备准入条件，不能用普通采样代替应用。
- [综合横向对比报告](09-comparison.md)：跨报告汇总；同条件分组，保留所有来源与拒绝记录。

实际运行使用 qtest report 自动生成含证据的 Markdown 与 JSON，再用 qtest compare 批量汇总；模板本身不作为测试结果导入。
