# QTest 报告模板：单机总报告

> 模板版本 v3 · 待填写字段不得用模拟数据冒充实测；此文件不是可导入的测试证据。

## 1. 报告摘要与适用范围

全部参测系统；汇总 L0、L1、L2，不能用内核成绩替代应用成绩。

填写：测试目的、核心问题、实例范围、完成情况、最有依据的发现、尚不能支持的结论。每条结论关联任务 ID 和证据文件。

自动化状态：已有相关自动报告内容；正式场景的未实现字段仍须标记未测。

## 8. 结果解释、限制与复测计划

- 按任务列出最有依据的发现，并附原始证据索引。
- 明确已测配置，不能把一台机器代表整条技术路线。
- 列出首期仍未覆盖的应用与下一轮接入条件。
- 填写相对参考和经典基线的实际发现；没有证据的优势结论留空。
- 区分采样误差、运行漂移、映射误差、参考误差和模型误差。
- 列明缺失数据、异常及下一轮可验证的改进假设。
